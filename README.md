> **太小聲的影片自動調高，太大聲的影片自動調低，嚴格將聲音鎖定在您耳朵設定的舒適範圍內！**

> **搭載「3倍速按鈕」：突破官方 2.0x 極限，播放器底欄專屬 ⚡倍速按鈕與快捷鍵，換片/廣告防止偷重設！**

## 💡 為什麼需要這個擴充套件？

觀看 YouTube 影片與播放清單時，最常見的五大痛點：
1. **創作者錄音忽大忽小**：有的影片細如蚊蚋、必須把音量調到最大，下一部影片或突發廣告卻又震耳欲聾。即便您把 YouTube 播放器滑桿固定，耳朵聽到的依然忽大忽小。
2. **畫質經常跳回低清模糊**：YouTube 自動畫質常因網路瞬間波動莫名跳到 480p 或 360p，每次換片都要繁瑣地手動點開設定齒輪重新選 1080p 或 4K。
3. **官方播放速度上限僅 2.0x，換片/廣告後偷重設**：長篇講座、教學或有聲書需要 3.0x 快速吸收，但 YouTube 原生上限只有 2.0x；且換片或廣告插播後速度經常被重設回 1.0x。
4. **想單純聽音樂卻被影片畫面干擾且耗電**：背景聽歌時，視訊串流依舊以 1080p/4K 耗損 GPU 進行視訊解碼，發熱耗電；且 YouTube 經常跳出「影片已暫停。要繼續觀看嗎？」中斷音樂播放。
5. **YouTube 官方隨機播放根本不隨機**：官方隨機播放常受演算法偏好加權，只在特定 10～20 首歌之間打轉，歌單後面的歌永遠播不到。

**YouTube 音量鎖定 ＆ 純音模式** 一站式解決這些痛點：
* **音量方面**：透過前級高精度時域分析與廣播壓平機，即時自動調高太小的影片、調低太大聲的爆音，耳朵聽到的始終是剛好舒適的目標音量（50% 基準點）。
* **畫質方面 (v1.6.0 新增)**：自訂鎖定偏好解析度（自動 / 1080p / 1440p / 4K / 720p），換片自動秒速鎖定；遇老影片不支援時智慧向下 Fallback 至最高可用解析度，且與純音模式完美連動。
* **倍速方面 (v1.6.0 新增)**：突破官方 2.0x 極限，在播放器底欄注入專屬 `⚡倍速按鈕`，支援一鍵循環切換（1.0x ➔ 1.5x ➔ 2.0x ➔ ⚡3.0x）與全域快捷鍵（`Shift+S`、`Shift+3`），並自動防 YouTube 偷重設速度。
* **純音方面**：一鍵切換深邃純音黑屏遮罩，播放器控制列專屬快捷按鈕與 `Shift+M` 快捷鍵，自動將串流降至 144p (small) 節省 85% GPU 算力與頻寬，並自動秒過廣告與暫停確認彈窗。
* **隨機方面**：採用真正的均勻無偏隨機（Fisher-Yates 原理）抽選未播過的影片；**預設關閉、完全不持久記憶**，每次重新打開 Chrome 瀏覽器都會自動回到關閉狀態。

## ✨ 核心特色

### 🎵 智慧情境自動調速 (Smart Speed Context Detection，v1.8.0 新增)
- 🧠 **8 層級權威音樂辨識架構**：
  1. **純聽音樂模式連動**：開啟純音遮罩時，一律鎖定 1.0x 原速。
  2. **白名單歌單與官方合輯**：命中白名單清單或官方專輯清單（`OLAK5uy_`、`RDMM` 等）自動 1.0x。
  3. **官方權威分類 Category: Music**：讀取 YouTube 官方後台微格式元數據（`category === 'Music'`），精準度 100%。
  4. **官方音樂影片類型 (musicVideoType)**：辨識官方 MV / UGC 音樂。
  5. **Topic 音樂主題頻道**：精準命中 YouTube 自動生成的歌手主題頻道（`- Topic`）。
  6. **官方音樂人認證徽章 (Verified Artist Badge)**：音符圖標與官方藝人徽章識別。
  7. **說明欄官方版權音樂結構化資訊**：精準偵測「Music in this video / 歌曲 / 演出者」授權欄位。
  8. **標題強特徵關鍵字規則**：涵蓋 Official Music Video, MV, Lyric Video, Remix, OST 等。
- ⚡ **看片 2.0x ＆ 聽歌 1.0x 自動切換**：
  - 遇到一般影片：自動切換為 **2.0x** 快速吸收新知。
  - 遇到音樂歌曲：自動切換為 **1.0x** 原速沉浸聆聽。
- 🛡️ **單片手動覆蓋保護 (Manual Override)**：
  - 在單一影片播放中，若您手動調整了速度，換片前絕不強制重設，完全尊重您的當下決定。
  - 換片後自動解除鎖定並對新影片重新進行智慧評估。
- 🔘 **播放器底欄即時回饋**：
  - 播放器右下角 `#ytp-speed-btn` 即時呈現 `🎵 1.0x`（紫色微光）或 `⚡ 2.0x` / `⚡ 3.0x`。
- 🎛️ **Popup 面板智慧情境膠囊**：
  - 面板頂部即時標註 `🎵 音樂 1.0x` 或 `🎬 看片 2.0x`。
  - 在「進階微調」中提供微型開關，可隨心所欲一鍵啟用或關閉此功能。

### 🎬 固定畫質 (Lock Quality)

- 📌 **全自動換片鎖定**：支援 Auto / 1080p FHD / 1440p 2K / 4K / 720p HD 偏好鎖定，每次換片或點擊推薦影片自動強制對齊設定。
- 🪜 **智慧向下 Fallback**：若影片最高僅支援 720p 或 1080p，系統自動梯級下探選擇最高可用畫質，絕不報錯或卡死播放器。
- 🔄 **純聽音樂雙向聯動**：開啟純音遮罩時自動降至 144p (small) 極致節流；關閉純音遮罩時，0 秒瞬間還原為您原本鎖定的畫質！

### ⚡ 3倍速按鈕 ＆ 現代旗艦倍速面板 (Speed Control)
- 🚀 **突破 YouTube 官方 2.0x 限制**：支援 0.25x 至極速 **⚡3.0x** 暴衝倍速（0.05x 無段微調滑桿 ＋ 常用倍速膠囊列）。
- 🔘 **播放器底欄專屬倍速面板**：直接在 YouTube 播放器右下角控制列注入 `#ytp-speed-btn`，點擊即展開旗艦面板（32px 超大字、[-] 滑桿 [+] 與常用膠囊）。
- ⌨️ **原生 ＆ 專屬全域快捷鍵**：
  - `<` (`Shift+,`)：減慢播放速度（每次 -0.25x，下限 0.25x）。
  - `>` (`Shift+.`)：加快播放速度（每次 +0.25x，上限 3.00x）。
  - `Shift+S`：循環切換速度（1.0x ➔ 1.5x ➔ 2.0x ➔ 3.0x）。
  - `Shift+3`：一鍵直達 3.0x 暴衝速 / 再次按下還原 1.0x。
  - 🖥️ **播放器即時 HUD Toast**：按下快捷鍵時於播放器畫面居中彈出半透明磨砂 Bezel 動畫，秒級反饋當前速度。
- 🛡️ **智能 ratechange 守護機制**：
  - 廣告播放中不干涉。
  - 廣告結束時精確還原使用者預期倍速（防止被 YouTube 偷重設回 1.0x）。
  - 使用者從 YouTube 原生齒輪選單調整時主動同步並尊重選擇，絕不衝突拉扯。

### 🎵 純聽音樂模式 (Music Mode 畫面遮擋與防中斷)
- 🌑 **沉浸式深邃暗黑遮罩**：深邃純黑背景搭配律動音波與唱片圖標，遮擋影片畫面，讓您專注於聲音本質（OLED 螢幕極致省電）。
- 🔘 **播放器控制列快捷按鈕**：直接在 YouTube 播放器右下角控制列注入專屬音樂圖示按鈕，一鍵秒切換。
- ⌨️ **全域鍵盤快捷鍵**：隨時按下 `Shift+M` 即刻秒切換純音遮罩與視訊畫面。
- ❄️ **144p 省電降頻節流**：開啟遮罩時自動將視訊解析度降至最低檔（144p），省下 85% 視訊解碼負載與高額頻寬，音質絲毫不受損；關閉時自動還原鎖定畫質。
- 🛡️ **背景防中斷 Watchdog**：自動跳過 YouTube「影片已暫停。要繼續觀看嗎？」確認彈窗，背景聽歌不再莫名被中斷。
- ⚡ **純音模式自動跳過廣告**：偵測到廣告時自動加速跳過，音樂體驗順暢連貫。

### 🔊 純淨抗噪零破音等化器 (Clean Anti-Noise Leveler)
- 🛡️ **4x 超取樣零溢出軟限制器 (WaveShaper Soft Clipper)**：底層採用 65536 點高精度雙曲正切軟飽和曲線，物理硬性鎖定輸出振幅絕對 $\le -0.5\text{ dBFS}$（峰值 $\le 0.945$），100% 杜絕任何外接 USB DAC、高傳真耳機或音效卡之數位削頂爆裂雜音 (Pops & Crackles)。
- 🚫 **智慧抗底噪門限與向下擴展 (Smart Noise Floor Gate & Downward Expander)**：門限設於 -46.0 dBFS。在安靜間歇或對話暫停時，自動凍結 AGC 增益並溫和向下衰減 -8 dB，徹底根絕「沙沙沙」底噪抽吸喘息聲 (Noise Floor Pumping)。
- 📻 **廣播級平滑壓平引擎 (DynamicsCompressor 10:1)**：採用 10:1 平滑廣播壓縮比搭配 380ms 自然釋放時間，徹底消除男低音波形調制失真 (Waveform Tracking Distortion)，聲音平整自然不發毛。
- ⚡ **零延遲高相容架構 (Zero Delay Node)**：拔除主通道 25ms 延遲緩衝，徹底消除藍牙耳機時鐘抖動 (Buffer Underruns) 與 Seek 跳轉殘留雜音。
- 🔄 **雙軌動態 AGC 連續跟蹤 (帶 0.35dB 防抖死區)**：長期 Leq RMS 微調宏觀基底，安全增益限制在 $[-18\text{ dB}, +12\text{ dB}]$，微小波動不重設參數，杜絕拉鍊噪音 (Zipper Noise)。
- 📋 **YouTube 官方 Content Loudness 響度元數據預讀 (Jump-Start)**：在影片載入第 0 秒即從 YouTube 播放器讀取後台轉檔測量之分貝偏差，0 秒瞬間對齊基準音量。
- 🎯 **自訂目標固定音量範圍 (0% ~ 100%)**：以 50% 為剛剛好的標準舒適基準，向上可平滑放大 +14 dB，向下可平滑減弱至 -26 dB，提供充裕且直覺的雙向微調空間。
- 🎨 **現代極簡 Design Craft 控制面板**：告別雜亂文字與滿版卡片，寬度 326px、零滾動條，核心功能一目了然，進階設定優雅收合。

### 🔀 播放清單真隨機 (True Shuffle) ＆ 白名單自動隨機
- 🎲 **無偏見均勻隨機 (Fair Uniform Shuffle)**：完全排除 YouTube 演算法推薦加權，整個播放清單內所有歌曲均享完全平等的隨機機率。

- ⭐ **白名單自動隨機 (Whitelist Auto-Shuffle，v1.7.0 新增)**：
  - **特定歌單自動隨機**：支援輸入播放清單 ID 或直接貼上 YouTube 網址，自動存入白名單（`chrome.storage.local` 持久儲存）。
  - **換片即刻自動啟動**：載入白名單歌單時**自動啟動真隨機**；切換至一般未加入白名單的清單時**自動還原關閉**，不再干擾系列教學或連續劇集！
  - **一鍵快捷星號按鈕**：在播放 YouTube 歌單時，擴充面板直接提供 `[⭐自動隨機]` / `[★已設自動隨機 (移除)]` 一鍵切換，完全無需繁瑣複製 ID。
- 🚪 **一般清單單次工作階段有效 (Session Storage)**：
  - **預設關閉 (Default: OFF)**。
  - **關閉 Chrome 瀏覽器後自動遺忘**，下次啟動 Chrome 依然維持關閉。
  - 只有在您手動開啟開關時，才會在此次瀏覽器階段對播放清單生效！
- ⏭️ **深度整合播放控制**：支援影片播畢自動跳轉，以及播放器介面「下一首 (Next Button)」快捷鍵攔截。

## 📥 安裝步驟 (免打包本機載入)

无需上架應用商店，只要 30 秒即可在任何 Chromium 瀏覽器中安裝使用：

### Step 1. 下載專案原始碼
點擊 GitHub 頁面右上角的綠色 **Code** 按鈕，選擇 **Download ZIP**（或使用 `git clone` 指令），並將壓縮檔解壓縮至您電腦中的固定資料夾。

```bash
git clone https://github.com/chris0320chirs/YT-Volume-Normalizer.git
```

### Step 2. 開啟瀏覽器擴充功能頁面
* **Google Chrome**：在網址列輸入 `chrome://extensions` 並按下 Enter。
* **Microsoft Edge**：在網址列輸入 `edge://extensions` 並按下 Enter。
* **Brave**：在網址列輸入 `brave://extensions` 並按下 Enter。

### Step 3. 開啟「開發人員模式」
在頁面右上角找到**「開發人員模式 (Developer mode)」**開關，將其切換為**開啟**。

### Step 4. 載入擴充套件
1. 點擊頁面左上角出現的**「載入未打包項目 (Load unpacked)」**按鈕。
2. 在彈出的檔案選擇視窗中，選取本專案的根目錄資料夾（即包含 `manifest.json` 的資料夾）。
3. 載入完成！您將會在列表中看到 **YouTube 音量範圍鎖定器與真隨機**。

## 🛠️ 技術架構

- **平台規格**：Chrome Extension Manifest V3 (Service Worker + Isolated Content Script + MAIN World Bridge + Popup)
- **音訊引擎**：Web Audio API
  - `MediaElementAudioSourceNode`：無損擷取 YouTube 播放串流
  - `AnalyserNode` (2048 FFT)：高解析度時域前饋 Leq RMS 計算
  - `DynamicsCompressorNode` (10:1 Broadcast)：平滑廣播級抗爆音壓平引擎，消除波形調制失真
  - `Smart Noise Floor Gate`：-46 dBFS 門限，安靜間歇凍結 AGC 並衰減 -8 dB 杜絕底噪抽吸
  - `WaveShaperNode` (4x Oversampling)：65536 點雙曲正切數學曲線，硬性鎖定 $\le -0.5\text{ dBFS}$ 零溢出
- **畫質與倍速核心 (MAIN World Bridge)**：
  - `content/page_bridge.js` 注入頁面主世界，直接操作 `movie_player.setPlaybackQualityRange()` 與 `getAvailableQualityLevels()`。
  - 實作向下智慧階梯 Fallback (`QUALITY_PRIORITY`)，杜絕畫質卡死。
  - 雙軌控制 `movie_player.setPlaybackRate()` 與 `HTMLVideoElement.playbackRate`，並監聽 `ratechange` 事件防止 SPA 導航偷重設。
- **隨機引擎**：Fisher-Yates 均勻隨機算法、YouTube SPA 路由點擊導航與 `ended` 攔截
- **通訊與儲存**：
  - 音量、畫質與倍速：`chrome.storage.local` 全域跨分頁持久記憶
  - 真隨機相關：`chrome.storage.session` 單次工作階段儲存（重開瀏覽器自動還原關閉）
