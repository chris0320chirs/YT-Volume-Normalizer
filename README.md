# 🎧 YouTube 音量範圍鎖定器 (YT Volume Normalizer)

> **太小聲的影片自動調高，太大聲的影片自動調低，將聲音嚴格鎖定在您耳朵設定的舒適音量範圍內！**

適用於 **Google Chrome**、**Microsoft Edge** 及所有 Chromium 核心瀏覽器的 Manifest V3 擴充套件。

---

## 💡 為什麼需要這個擴充套件？

觀看 YouTube 影片時，最惱人的體驗莫過於：
* **不同創作者錄音音量落差極大**：有的創作者講話細如蚊蚋，不得不把電腦音量拉到最大；下一部影片或突發廣告卻又震耳欲聾、音量爆炸。
* **YouTube 原生播放器音量即使固定，體感音量依然不固定**：因為 YouTube 播放器滑桿只是單純的乘數，無法解決原片錄製分貝過低或過高的根本落差。

**YouTube 音量範圍鎖定器** 透過瀏覽器 Web Audio API 於前級即時偵測每部影片的實際錄音響度，自動為您「平滑調高太小聲的片段」並「瞬間壓低太吵的爆音與廣告」，讓您耳朵聽到的聲音永遠維持在同一舒適範圍內！

---

## ✨ 核心特色

- 🔈 **太小聲自動調高 (Auto Boost)**：即時偵測偏小影片，平滑自動放大增益（最高支援 `+24 dB`，約 16 倍提升），徹底告別吃力聽音。
- 🔊 **太大聲自動調低 (Auto Cut)**：遇突發大叫、刺耳特效或吵雜廣告，於 `0.05 秒` 內自動調低（最高壓小至 `-24 dB`），保護聽力不被嚇到。
- 🎯 **自訂目標固定音量範圍**：在彈出面板中隨心設定「耳朵想聽到的固定大小」（預設 100% 標稱 -16 dBFS），所有影片均自動對齊此基準。
- ⚡ **換片 0.1 秒瞬時收斂 (Fast Convergence)**：切換新影片或 Shorts 時，0.1 秒內迅速完成初次取樣並咬定目標音量，換片完全不突兀。
- 🚫 **雙重語音閘門 (Silence Gate，絕無底噪抽吸)**：對話暫停或安靜間歇自動凍結增益，絕不盲目放大背景沙沙聲或環境噪音。
- 🛡️ **磚牆防破音限制器 (Brickwall Safety Limiter)**：輸出端強制鎖定安全閥值，杜絕破音與削頂失真。
- 🧹 **100% 原生純淨 (Zero DOM Mutation)**：絕不污染或修改 YouTube 播放器介面，不影響劇院模式與全螢幕。
- 📊 **三態動態指示燈與即時 VU 量表**：清楚顯示當前影片是「太小調高 ⬆️」、「在設定範圍內 🎯」還是「太大調低 ⬇️」，以及即時補償分貝值。

## 📥 安裝步驟 (免打包本機載入)

無需上架應用商店，只要 30 秒即可在任何 Chromium 瀏覽器中安裝使用：

### Step 1. 下載專案原始碼
點擊 GitHub 頁面右上角的綠色 **Code** 按鈕，選擇 **Download ZIP**（或使用 `git clone` 指令），並將壓縮檔解壓縮至您電腦中的固定資料夾。

```bash
git clone https://github.com/chris0320chirs/YT-Volume-Normalizer.git
```

### Step 2. 開啟瀏覽器擴充功能頁面
* **Google Chrome**：在網址列輸入 `chrome://extensions` 並按下 Enter。
* **Microsoft Edge**：在網址列輸入 `edge://extensions` 並按下 Enter。
* **Brave**：在網址列輸入 `brave://extensions` 並按下 Enter。

### Step 3. 開啟「開發人員模式」
在頁面右上角找到**「開發人員模式 (Developer mode)」**開關，將其切換為**開啟**。

### Step 4. 載入擴充套件
1. 點擊頁面左上角出現的**「載入未打包項目 (Load unpacked)」**按鈕。
2. 在彈出的檔案選擇視窗中，選取本專案的根目錄資料夾（即包含 `manifest.json` 的資料夾）。
3. 載入完成！您將會在列表中看到 **YouTube 音量平衡鎖定器 (YT Volume Normalizer)**。

## 🎮 使用指南

1. **釘選外掛**：點擊瀏覽器右上角的拼圖圖示（擴充功能選單），找到 **YouTube 音量平衡鎖定器** 並將它**釘選**到工具列。
2. **開啟 YouTube 播放影片**：打開任意 [YouTube](https://www.youtube.com) 影片（若分頁原本已開啟，請先按 **F5 重新整理**）。
3. **點擊工具列圖示開啟面板**：
   - **目標固定音量滑桿**：拖動以設定您耳朵最舒適的音量（預設 `100%` 為標準舒適度，可按「重設」恢復）。
   - **觀察三態指示燈**：
     - `[ ⬆️ 太小・自動調高 ]`：偵測到錄音太小時亮起綠燈，自動拉大音量。
     - `[ 🎯 在設定範圍內 ]`：音量已完美符合您的設定目標時亮起藍燈。
     - `[ ⬇️ 太大・自動調低 ]`：遇爆音或廣告時亮起琥珀燈，即時壓低。
   - **音量範圍嚴格度**：
     - **嚴格鎖定 (±1dB)**：極致壓平，不容許任何落差。
     - **標準舒適 (±2dB，推薦)**：日常觀看最佳推薦，兼顧自然語音動態。
     - **寬鬆動態 (±3.5dB)**：適合電影與交響樂欣賞。

## 🛠️ 技術架構

- **平台規格**：Chrome Extension Manifest V3
- **音訊引擎**：Web Audio API
  - `MediaElementAudioSourceNode`：無損擷取 YouTube 播放串流
  - `AnalyserNode` (2048 FFT)：高解析度時域前饋 RMS 計算
  - `GainNode`：即時無級自適應平滑補償
  - `DynamicsCompressorNode`：磚牆式極限防破音保護
- **通訊與儲存**：`chrome.storage.local` 全域跨分頁狀態記憶、`chrome.tabs.connect` 輕量 30fps 即時通訊 Port
