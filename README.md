# 🎧 YouTube 音量範圍鎖定器 ＆ 播放清單真隨機 (YT Volume & True Shuffle)

> **太小聲的影片自動調高，太大聲的影片自動調低，嚴格將聲音鎖定在您耳朵設定的舒適範圍內！**  
> **額外搭載「播放清單真隨機」：破除 YouTube 演算法偏見，預設關閉且單次工作階段有效，重開瀏覽器自動恢復關閉！**

適用於 **Google Chrome**、**Microsoft Edge**、**Brave** 及所有 Chromium 核心瀏覽器的 Manifest V3 擴充套件。

---

## 💡 為什麼需要這個擴充套件？

觀看 YouTube 影片與播放清單時，最常見的兩大痛點：
1. **創作者錄音忽大忽小**：有的影片細如蚊蚋、必須把音量調到最大，下一部影片或突發廣告卻又震耳欲聾。即便您把 YouTube 播放器滑桿固定，耳朵聽到的依然忽大忽小。
2. **YouTube 官方隨機播放根本不隨機**：官方隨機播放常受演算法偏好加權，只在特定 10～20 首歌之間打轉，或是每次隨機順序都雷同，歌單後面的歌永遠播不到。

**YouTube 音量範圍鎖定器與真隨機** 同時解決這兩大問題：
* **音量方面**：透過前級高精度時域分析，即時自動調高太小的影片、調低太大聲的爆音，讓您耳朵聽到的始終是同一個目標音量範圍。
* **隨機方面**：採用真正的均勻無偏隨機（Fisher-Yates 原理）抽選未播過的影片；而且**預設關閉、完全不持久記憶**，每次重新打開 Chrome 瀏覽器都會自動回到關閉狀態，只有在您手動開啟時才會於本次播放清單中生效！

## ✨ 核心特色

### 🔊 廣播級音量極限鎖定 (Broadcast-Grade Leveler)
- 📻 **20:1 極限壓平引擎 (Hardware C++ DSP Compressor)**：底層採用原生瀏覽器 C++ `DynamicsCompressorNode`，20:1 極致壓縮比，20dB 的動態落差被硬性壓平至 1dB 內，保證每支影片、每段對話聲音聽感完全一致！
- ⚡ **25ms 前瞻預判緩衝 (Lookahead Buffer)**：音訊路徑加入 25ms 微幅延遲緩衝，偵測器提前 0.025 秒「看見未來」，在爆音抵達揚聲器前就已平滑壓制妥當，100% 杜絕刺耳驚嚇且唇音完全同步。
- 📋 **YouTube 官方 Content Loudness 響度元數據預讀 (Jump-Start)**：在影片載入第 0 秒即從 YouTube 播放器讀取後台轉檔測量之分貝偏差，0 秒瞬間對齊基準音量。
- 🔄 **雙軌動態 AGC 連續跟蹤 (Continuous Sliding Leq AGC)**：不依賴單一靜態數值，播放中持續即時分析長效 Leq RMS，無論影片中途切換安靜訪談或狂熱吼叫，自動在 0.6～1.0 秒內平滑無感修正。
- 🎚️ **三種等化風格模式 (Equalizer Modes)**：
  - 📻 **廣播級恆定 (預設推薦)**：20:1 極致壓平，徹底解決忽大忽小，耳朵聽到的每一秒音量完全恆定。
  - 🗣️ **人聲強效**：更深捕獲微弱低語與訪談教學，字字清晰。
  - 🎵 **音樂原味**：保留樂曲呼吸與自然起伏，防止樂器層次過度壓扁。
- 🔈 **太小聲自動調高 (Auto Boost)**：即時偵測偏小影片，平滑自動放大增益（最高支援 `+22 dB`）。
- 🔊 **太大聲自動調低 (Auto Cut)**：遇突發大叫、刺耳特效或吵雜廣告，自動快速調低（最高壓小至 `-18 dB`），保護聽力不被震耳。
- 🎯 **自訂目標固定音量範圍**：在彈出面板中隨心設定「耳朵想聽到的固定大小」（預設 100% 為標準推薦），所有影片均自動縮放對齊此基準。
- 🚫 **智慧語音閘門 (Silence Gate，絕無底噪抽吸)**：對話暫停或安靜間歇自動凍結增益，絕不盲目放大背景沙沙聲或環境噪音。
- 🛡️ **磚牆防破音限制器 (Brickwall Safety Limiter)**：輸出端強制鎖定 -0.5 dBFS 安全閥值，杜絕破音與削頂失真。
- 📊 **三態動態指示燈與即時 VU 量表**：清楚顯示當前影片是「太小調高 ⬆️」、「在設定範圍內 🎯」還是「太大調低 ⬇️」，以及即時補償分貝值與官方響度。

### 🔀 播放清單真隨機 (True Shuffle)
- 🎲 **無偏見均勻隨機 (Fair Uniform Shuffle)**：完全排除 YouTube 演算法推薦加權，整個播放清單內所有歌曲均享完全平等的隨機機率。
- 🔁 **不重複輪播循環**：系統會自動追蹤已播過的影片，整張清單播完前絕不重複，清單全數播完後自動重啟新一輪隨機。
- 🚪 **單次工作階段有效 (Session Storage)**：
  - **預設關閉 (Default: OFF)**。
  - **關閉 Chrome 瀏覽器後自動遺忘**，下次啟動 Chrome 依然維持關閉。
  - 只有在您手動開啟開關時，才會在此次瀏覽器階段對播放清單生效！
- ⏭️ **深度整合播放控制**：支援影片播畢自動跳轉，以及播放器介面「下一首 (Next Button)」快捷鍵攔截。

## 📥 安裝步驟 (免打包本機載入)

无需上架應用商店，只要 30 秒即可在任何 Chromium 瀏覽器中安裝使用：

### Step 1. 下載專案原始碼
點擊 GitHub 頁面右上角的綠色 **Code** 按鈕，選擇 **Download ZIP**（或使用 `git clone` 指令），並將壓縮檔解壓縮至您電腦中的固定資料夾。

```bash
git clone https://github.com/chris0320chirs/YT-Volume-Normalizer.git
```

### Step 2. 開啟瀏覽器擴充功能頁面
* **Google Chrome**：在網址列輸入 `chrome://extensions` 並按下 Enter。
* **Microsoft Edge**：在網址列輸入 `edge://extensions` 並按下 Enter。
* **Brave**：在網址列輸入 `brave://extensions` 並按下 Enter。

### Step 3. 開啟「開發人員模式」
在頁面右上角找到**「開發人員模式 (Developer mode)」**開關，將其切換為**開啟**。

### Step 4. 載入擴充套件
1. 點擊頁面左上角出現的**「載入未打包項目 (Load unpacked)」**按鈕。
2. 在彈出的檔案選擇視窗中，選取本專案的根目錄資料夾（即包含 `manifest.json` 的資料夾）。
3. 載入完成！您將會在列表中看到 **YouTube 音量範圍鎖定器與真隨機**。

## 🎮 使用指南

1. **釘選外掛**：點擊瀏覽器右上角的拼圖圖示（擴充功能選單），找到 **YouTube 音量鎖定 ＆ 真隨機** 並將它**釘選**到工具列。
2. **開啟 YouTube 播放影片**：打開任意 [YouTube](https://www.youtube.com) 影片（若分頁原本已開啟，請先按 **F5 重新整理**）。
3. **點擊工具列圖示開啟面板**：
   - **目標固定音量滑桿**：拖動以設定您耳朵最舒適的音量（預設 `100%` 為標準舒適度，可按「重設」恢復）。
   - **觀察三態指示燈**：
     - `[ ⬆️ 太小・自動調高 ]`：偵測到錄音太小時亮起綠燈，自動拉大音量。
     - `[ 🎯 在設定範圍內 ]`：音量已完美符合您的設定目標時亮起藍燈。
     - `[ ⬇️ 太大・自動調低 ]`：遇爆音或廣告時亮起琥珀燈，即時壓低。
   - **播放清單真隨機開關**：
     - 當您進入包含清單的網址（URL 含 `list=`）時，面板會提示偵測到的清單總數。
     - 勾選開關即可啟動真隨機，當影片播放結束或點擊「下一首」時會自動均勻隨機抽選下一首未播歌曲。
     - **關閉 Chrome 瀏覽器後，此開關自動恢復為關閉**。

## 🛠️ 技術架構

- **平台規格**：Chrome Extension Manifest V3 (Service Worker + Content Script + Popup)
- **音訊引擎**：Web Audio API
  - `MediaElementAudioSourceNode`：無損擷取 YouTube 播放串流
  - `AnalyserNode` (2048 FFT)：高解析度時域前饋 RMS 計算
  - `GainNode`：即時無級自適應平滑補償
  - `DynamicsCompressorNode`：磚牆式極限防破音保護
- **隨機引擎**：Fisher-Yates 均勻隨機算法、YouTube SPA 路由導航
- **通訊與儲存**：
  - 音量相關：`chrome.storage.local` 全域跨分頁持久記憶
  - 真隨機相關：`chrome.storage.session` 單次工作階段儲存（重開瀏覽器自動還原關閉）
